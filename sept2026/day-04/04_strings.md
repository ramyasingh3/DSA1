# String to Integer (atoi)

## Problem
Implement atoi with overflow rules.

## Example
```
Input: [-1, -2, 36, 46, -20, -8, -8]
Output: (compute according to problem statement)
```

## Constraints

- Aim for better than naive O(n^2) when possible

## Hint
