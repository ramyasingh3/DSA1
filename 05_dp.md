# Dynamic Programming

## Q1. Coin Change

You are given coins of different denominations `coins` and a total amount `amount`. Return the fewest number of coins needed to make up that amount. If it cannot be made, return `-1`.

You may assume an infinite number of each coin.

**Example**
```
Input: coins = [1,2,5], amount = 11
Output: 3
Explanation: 11 = 5 + 5 + 1
```

**Constraints**
- `1 ≤ coins.length ≤ 12`
- `1 ≤ coins[i] ≤ 2^31 - 1`
- `0 ≤ amount ≤ 10^4`

**Hint:** `dp[x] = min(dp[x - coin] + 1)` over all coins.

## Q2. Longest Increasing Subsequence

Given an integer array `nums`, return the length of the longest strictly increasing subsequence.

**Example**
```
Input: nums = [10,9,2,5,3,7,101,18]
Output: 4
Explanation: [2,3,7,101] or [2,5,7,101]
```

**Follow-up:** Achieve `O(n log n)` using patience sorting / binary search on tails.

## Q3. Edit Distance

Given two strings `word1` and `word2`, return the minimum number of operations required to convert `word1` to `word2`.

Allowed operations (each costs 1):
- Insert a character
- Delete a character
- Replace a character

**Example**
```
Input: word1 = "horse", word2 = "ros"
Output: 3
Explanation: horse → rorse → rose → ros
```

**Constraints**
- `0 ≤ word1.length, word2.length ≤ 500`
- Lowercase English letters only
